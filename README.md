# octopus-sdk

Librairie pour les projets Octopus.

## Usage

Installer dans un projet:

```bash
npm i @saooti/octopus-sdk
```

Utiliser dans un projet en local:
```bash
# Dans le SDK
npm link  # Nécessaire uniquement la première fois
npm build --watch

# Dans le projet
npm link @saooti/octopus-sdk
```
