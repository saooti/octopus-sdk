# Configuration style

Cf [_variables.scss](../src/style/_variables.scss).

Ces variables sont séparées en deux blocs principaux :
- Les variables génériques : elles sont peu nombreuses, et permettent de
  rapidement modifier le style de l'ensemble de l'application
- Les variables spécifiques aux composants : ces variables impactent un
  composant précis. Elles se basent géneralement sur les variables génériques.
